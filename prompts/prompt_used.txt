CLASSIFICATION PROMPT
================================================================================

For every complaint narrative, determine:

1. PRODUCT: What financial product is it about?
   Options: Credit Card | Mortgage | Student Loan | Bank Account | 
            Debt Collection | Credit Reporting | Vehicle Loan | 
            Personal Loan | Prepaid Card | Other

2. ISSUE CATEGORY: What's the main problem?
   Options: Billing Error | Fraud | Account Access | Customer Service | 
            Harassment | Account Ownership | Fees/Charges | 
            Credit Reporting | Other

3. SEVERITY SCORE: How urgent is it?
   Scale: 1-10 
   (1=low priority, 5=medium, 8+=critical/fraud)

4. SENTIMENT: How angry is the customer?
   Options: Angry | Frustrated | Confused | Neutral | Satisfied

5. RECOMMENDED ROUTING: Who should handle it?
   Options: Support | Legal | Fraud Team | Escalation | 
            Billing Dept | Credit Dispute Team | Account Services

6. CONFIDENCE: How sure are we?
   Scale: 0.0-1.0 
   (0.95 = 95% confident, <0.75 = needs manual review)

### SEVERITY SCORE CALCULATION

Risk-based scoring system (1-10 scale):

def calculate_severity(narrative, issue_category, product):
    score = 5  # Base score (medium)
    
    # High severity indicators (+2 to +4)
    if contains(['fraud', 'stolen', 'identity theft', 'unauthorized']):
        score += 4
    if contains(['foreclosure', 'eviction', 'legal action', 'lawsuit']):
        score += 3
    if contains(['emergency', 'urgent', 'immediate', 'critical']):
        score += 2
    if contains(['harass', 'threatening', 'abusive']):
        score += 2
    
    # Medium severity indicators (+1)
    if contains(['dispute', 'incorrect', 'error', 'wrong']):
        score += 1
    if contains(['multiple', 'repeated', 'several times']):
        score += 1
    
    # Low severity indicators (-2)
    if contains(['question', 'inquiry', 'wondering', 'clarify']):
        score -= 2
    
    # Adjust by issue category
    if issue_category in ["Fraud", "Identity Theft"]:
        score += 2
    elif issue_category == "Customer Service":
        score -= 1
    
    # Cap between 1-10
    return max(1, min(10, score))

Scoring Guide:
- 10: Critical fraud, identity theft, immediate legal threat
- 8-9: High-risk issues (foreclosure, harassment, major errors)
- 6-7: Significant problems requiring escalation
- 4-5: Standard complaints, moderate priority
- 1-3: Routine inquiries, minor issues

def analyze_sentiment(narrative):
    text = clean_text(narrative)
    
    if not text or len(text) < 20:
        return "Neutral"
    
    # Count emotion indicators
    angry_words = ['outraged', 'disgusted', 'unacceptable', 'ridiculous', 
                   'furious', 'appalled', 'scam', 'theft', 'illegal', 'violated']
    frustrated_words = ['frustrated', 'disappointed', 'dissatisfied', 'unhappy', 
                        'repeatedly', 'still waiting', 'no response', 'ignored']
    confused_words = ['confused', 'unclear', "don't understand", 'wondering', 
                      'not sure', 'help', 'explain', 'question']
    
    angry_count = count_keywords(angry_words)
    frustrated_count = count_keywords(frustrated_words)
    confused_count = count_keywords(confused_words)
    
    # Check emotional indicators
    exclamation_count = text.count('!')
    caps_ratio = uppercase_percentage()
    
    # Classification rules
    if angry_count >= 2 or exclamation_count >= 3 or caps_ratio > 0.3:

### ROUTING RECOMMENDATION

Intelligent department assignment based on issue and severity:

def recommend_routing(issue_category, severity, sentiment):
    
    # Priority-based routing
    if issue_category == "Fraud" or severity >= 9:
        return "Fraud Team"
    elif severity >= 8 or sentiment == "Angry":
        return "Escalation"
    elif issue_category in ["Billing Error", "Fees/Charges"]:
        return "Billing Dept"
    elif issue_category == "Harassment":
        return "Legal"
    elif issue_category in ["Account Access", "Account Ownership"]:
        return "Account Services"
    elif issue_category == "Credit Reporting":
        return "Credit Dispute Team"
    else:
        return "Support"

Routing Logic:
- Fraud Team: All fraud cases + severity 9-10
- Escalation: Severity 8+ or angry sentiment
- Legal: Harassment, threats, regulatory violations
- Billing Dept: Billing errors, fee disputes
- Credit Dispute Team: Credit report issues
- Account Services: Account access/ownership
- Support: General inquiries, standard cases

### CONFIDENCE CALCULATION

Quality assurance metric (0.0-1.0):

def calculate_confidence(narrative, product_field, issue_field):
    confidence = 0.5  # Base confidence
    
    # Narrative availability (major factor)
    if has_narrative and len(narrative) > 50:
        confidence += 0.3
    elif has_narrative and len(narrative) > 0:
        confidence += 0.15
    
    # Field completeness
    if product_field is not empty:
        confidence += 0.1
    if issue_field is not empty:
        confidence += 0.1
    
    # Cap at 1.0
    return min(1.0, confidence)

Confidence Levels:
- 1.0: Full narrative + complete fields (high certainty)
- 0.7-0.9: Partial information
- 0.7: No narrative (product/issue fields only)
- <0.75: Flag for manual review
