WHAT LIVES WHERE
================================================================================

Root Level:

  • FOLDER_STRUCTURE.txt - This reference document

  • 4 PNG visualizations at 300 DPI

  • Reserved for future sample datasets
  • Currently empty

  • VALIDATION_SUMMARY.md - Detailed accuracy validation methodology

prompts/:
  • prompt_used.txt - Complete classification logic documentation

  • Technical reference for understanding how classification works

reports/:
  • classification_report.txt - Statistics on 100 complaints processed
  • metrics_summary.txt - Distribution breakdowns and analysis
  • validation_form.txt - Template for manual validation review

================================================================================
DATA FLOW
================================================================================

Input:
  complaint_data.xlsx (284,500 rows, 18 columns)
  └─> Sample: First 100 complaints extracted

Processing:
  Python script with rule-based NLP
  └─> Classification across 6 dimensions
      ├─ Product (7 categories)
      ├─ Issue Category (8 types)
      ├─ Severity (1-10 scale)
      ├─ Sentiment (5 emotions)
      ├─ Routing (7 departments)
      └─ Confidence (0.0-1.0)

Output:
  data/outputs/classified_sample_100.json
  └─> 100 complaints with structured classification
      └─> Validation on first 10 (90% accuracy)

Visualization:
  charts/*.png (4 charts)
  └─> Embedded in README.md

Documentation:
  docs/*.md + reports/*.txt
  └─> Analysis and validation results
